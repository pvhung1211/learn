
### **Tell me about a challenging technical problem you solved recently.**
So, in my current project, it is an AI-powered chatbot, and users have a page that displays all messages, including user questions and AI answers. On this page, sometimes we need to display a large list of messages, and at that point the page becomes very laggy. To fix this, first we optimized our components by using React APIs like `useMemo`, `useCallback`, and `memo`. This reduced unnecessary re-rendering. After that, we used a JavaScript package called TanStack Virtual. Basically, it helps us display only the message components that are currently in the viewport, which reduces a lot of unviewed components outside the viewport. As a result, the page feels smoother and we get better performance.
