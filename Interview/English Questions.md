### **5. Can you tell me about a challenging project or bug?**
 The biggest challenge I faced was supporting many tenants in one project. Before, we used different branches for each tenant, and we had to copy code from one branch to another. It was hard to manage because the branches became different over time, some fixes were missing in other branches, and we spent a lot of time keeping everything in sync. As the front-end lead, I suggested a better way. I created one base code for all tenants. Now we use environment variables to turn features on or off for each tenant. This removes all the copy-pasting and makes the project much easier to maintain.
